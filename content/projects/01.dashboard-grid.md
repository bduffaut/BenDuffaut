At Reveal Security I built a production dashboard on top of GridStack.js. It worked, but I kept
running into the edges of someone else's abstraction. So afterwards I wrote my own grid engine.

## What it does

You give it a list of widgets and a component for each widget type. It handles the rest:

- Drag and resize from any side or corner, with collision handling and float-up, float-left or static modes
- Undo and redo, multi-select with Shift+click or a selection box, and snap guides
- Full keyboard editing with screen reader announcements
- Responsive layouts for desktop, tablet and phone
- Dragging between grids, into grids nested inside widgets, and in from a sidebar
- Pin, lock and resize-lock modes, trash zones, and auto-arrange into the tightest layout
- Lazy, collapsible and content-sized widgets
- localStorage persistence, named layout presets, and versioned JSON with migrations
- Animation presets and arrival effects, all respecting reduced motion
- Crash-safe widgets and self-repairing layout data

## Using it

```vue
<DashboardGrid v-model="widgets" :components="{ chart: SalesChart }" />
```

That's the whole integration. Everything else is opt-in props.

## How it's built

The library and a demo app live in one workspace. The demo consumes the package exactly like an
outside project would, so anything the demo needs has to be a real, documented export. Headless
helpers (add menus, pin menus, drag-aware toolbars) let apps build their own chrome on top.

The demo is a fictional security-operations console called Sentinel. Its look (dark surfaces,
chamfered panels, teal signal color) is where this site's design comes from.
