Pick your topics when you sign up, then generate a briefing: the backend pulls live articles from
NewsAPI, scrapes the full text, and has GPT-4o filter and summarize what's actually relevant to you.

## What I built

- **Data layer.** Integrated MongoDB (Mongoose on Atlas) with the Express API for users, preferences and briefings.
- **Mobile app.** Built the Flutter client for iOS and Android against the same API as the web app.
- **Briefing flow.** Fixes across the stack to get end-to-end briefing generation working, plus the web app.

## The system

- Express API in TypeScript with password plus email OTP login, JWT sessions, and per-user rate limits and quotas
- News intake from NewsAPI.org, plus a scraper for full-text extraction
- GPT-4o summaries filtered against each user's interests
- React 19 + Vite on web and Flutter on mobile, sharing Zod contracts from one package
- GitHub Actions deploying to a DigitalOcean droplet under PM2
